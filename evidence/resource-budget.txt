The namespace quota permits 2 CPU requests, 4 CPU limits, 2 GiB memory requests and 4 GiB memory limits. The planned storage Pod plus four client Pods request 900m CPU and 1 GiB memory, with limits of 3 CPU and 3 GiB memory, so the deployment remains within quota. ResourceQuota constrains aggregate declared resources; it does not reserve physical hardware or limit S3 object-storage bytes.
